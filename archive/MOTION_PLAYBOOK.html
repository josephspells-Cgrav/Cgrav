00How to use this file

This file is the Phase 2 working catalog. The user has reviewed a static draft and wants to apply motion section by section, voice-driven. Each entry below is a copy-paste-ready block — exact cascade timings, ambient loop specs, hover gesture utilities, spring configs, per-section recipe sequences. Look up by section pattern (§07) or by voice vocabulary (§08), paste the block, describe what landed.

When this file fires

User voice trigger phrases (any activates Phase 2):

  • "phase 2" / "Phase 2"
  • "add motion" / "let's add motion" / "motion it up"
  • "now let's animate" / "now animate" / "animate that"
  • "load the playbook" / "load motion playbook"
  • "let's wrap [section] in [motion vocab]"
  • Specific vocabulary on a specific element ("typed-in on the hero H1", "underline left-to-right on these headings", "stagger the cards from the left")

First action on Phase 2 trigger

1. Output: Motion playbook loaded — Phase 2 active.
2. Scaffold the 9 motion primitives in components/motion/ (see STRUCTURE §06.7).
3. Output: Motion primitives loaded (Phase 2 active): FadeUp, Stagger, TypeIn,
   HeadingWithUnderline, AnimatedUnderline, SlideIn, Marquee, StatCounter, PerimeterDraw
4. Ask: which section do you want to start with? (Default: hero, top-to-bottom.)

Application loop (per section)

  1. User identifies section + vocabulary ("typed-in on hero H1", "stagger cards from left").
  2. Agent finds the matching block in §07 (section recipe) or §02 (primitive vocabulary) or §08 (voice index).
  3. Agent pastes the block into the section's JSX, adapting only palette tokens / text content / per-card count. NEVER alter cascade delays, durations, easing, or stagger childDelay from the canonical block.
  4. Agent reports one line: [section] · [primitive applied] · [delay/duration/childDelay/etc as relevant].
  5. User reviews (Playwright capture available on request), confirms or redirects.
  6. Loop to next section.
Hard rule Copy-paste from blocks, never improvise. The catalog values (cascade 0.00/0.50/0.45, ambient 2.4s/1.8s, hover 300ms/200ms, spring 260/18) are exact. Improvising defaults to model-compressed values that fail consistently. If the user describes a motion not in this catalog, surface that as a question ("the playbook doesn't have X — want me to browse MOTION_DOCTRINE.html for it, or describe what you have in mind?") rather than improvising.

01Universal substrate — every motion-using file

Four universal constants. Declared once per primitive file (or in a shared constants file the project agrees on). AM declares ENTER_EASE at the top of every primitive + 27 section files (no shared motion/easing.ts — each file copies the constant).

1.1 · Entry ease curve (ENTER_EASE)

const ENTER_EASE = [0.16, 1, 0.3, 1] as const;
// Cubic-bezier expo-out. Every entry transition uses this.
// NEVER "linear" for entries. NEVER "ease-in-out" for entries
// (ease-in-out is reserved for ambient infinite-loop pulses only).

1.2 · Positive 200px pre-trigger viewport margin

viewport={{ once: true, margin: "200px" }}
// Default on FadeUp / Stagger / SlideIn whileInView triggers.
// Positive margin EXPANDS the IntersectionObserver root, firing reveal
// 200px BEFORE element enters viewport. Eliminates catch-up feel.
// Negative margins ("-180px", "-160px") reserved for inner-bullet
// stagger delay only — never as section reveal default.

1.3 · Reduced-motion floor (every primitive)

"use client";
import { useReducedMotion, motion } from "framer-motion";

export function FadeUp({ children, ...rest }) {
  const prefersReducedMotion = useReducedMotion();
  if (prefersReducedMotion) return <div>{children}</div>;
  return <motion.div ...>{children}</motion.div>;
}

// Plus globals.css safety net:
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

1.4 · Ambient cadence pair

// 2.4s — diamond ◆ bullet markers, spec/thread/glance bullets, section bridges
animate={{ opacity: [0.65, 1, 0.65], scale: [1, 1.18, 1] }}
transition={{ duration: 2.4, repeat: Infinity, ease: "easeInOut", delay: index * 0.3 }}

// 1.8s — alert dots on CTA pips, "active" labels, sticky CTA reinforcement
animate={{ opacity: [0.6, 1, 0.6], scale: [1, 1.3, 1] }}
transition={{ duration: 1.8, repeat: Infinity, ease: "easeInOut" }}

// Loops use ease: "easeInOut", NOT the ENTER_EASE expo-out.

02Primitive vocabulary — by name

9 primitives. Each has canonical defaults + variant blocks. Each block is copy-paste-ready with palette tokens marked {accent} / {brand-deep} for swap-in.

2.1 · FadeUp

Opacity 0→1, y 20→0. Default for any "rise into view" content reveal.

// Standard usage
<FadeUp delay={0.0} duration={0.6}>
  <p className="...">Body copy.</p>
</FadeUp>

// With y override (subhead variant: y:24, dur 0.7s, delay 0.45s)
<FadeUp delay={0.45} duration={0.7} y={24}>
  <p className="text-lg text-muted">Subhead copy.</p>
</FadeUp>

// Canonical primitive — defaults: dur 0.6s · delay 0 · y 20 · margin "200px" · ease ENTER_EASE

Per-child opacity 0→1, y 16→0 via variants. Wrap any list/grid for cascading reveal.

2.8 · StatCounter (auto-scale by target)

Numeric count-up; non-numeric values get opacity+y fade-up.

03Cascade ladder — header reveal sequence

Every section header runs the same orchestrated cascade. Delays additive — each step waits for the previous to land. Sub-1.5s total = stiff. Doctrine cascade runs ~3-4s per section.

3.1 · Standard depth (sections 2-5 from top of page)

// Eyebrow — fires first, sets cadence
<FadeUp delay={0.0} duration={0.7}>
  <Eyebrow>What we fix</Eyebrow>
</FadeUp>

// H2 — TypeIn cinematic + underline draws after typeIn completes
<HeadingWithUnderline fullWidth glow cinematic typeIn
  typeInDelay={0.10}
  delay={0.50}
  duration={0.60}
  as="h2"
>
  Asheville plumbing operations
</HeadingWithUnderline>

// Subhead — starts BEFORE H2 finishes, feels concurrent not rigid
<FadeUp delay={0.45} duration={0.7} y={20}>
  <p className="text-lg text-muted">Subhead copy.</p>
</FadeUp>

// Right-col fill — slightly behind subhead
<FadeUp delay={0.55} duration={0.7} y={24}>
  <StatCluster anchors={...} />
</FadeUp>

// Cards container — kicks off card cascade
<Stagger childDelay={0.08} delay={0.2}>
  {cards.map(...)}
</Stagger>

3.2 · Deep depth (sections 5+ from top)

Shift entire ladder later by ~0.4s. Eyebrow / H2 / Subhead delays become 0.85-1.1s instead of 0.45-0.6s. Compensates for cognitive expectation slow-down at fold 4+.

// Deep eyebrow
<FadeUp delay={0.4} duration={0.7}>...</FadeUp>

// Deep H2
<HeadingWithUnderline ... delay={0.9} typeInDelay={0.1} duration={0.6}>...</HeadingWithUnderline>

// Deep subhead
<FadeUp delay={0.85} duration={0.7} y={20}>...</FadeUp>

// Deep right-col
<FadeUp delay={0.95} duration={0.7} y={24}>...</FadeUp>

3.3 · Per-card inner cascade (cd = i × 0.06-0.12s per card)

{cards.map((c, i) => {
  const cd = i * 0.08; // card delay base — adjust 0.06-0.12 by feel

  return (
    <StaggerItem key={i}>
      <Card>
        {/* Icon spring-pop */}
        <motion.div
          initial={{ scale: 0.5, opacity: 0 }}
          whileInView={{ scale: 1, opacity: 1 }}
          transition={{ type: "spring", stiffness: 260, damping: 18, delay: 0.30 + cd, duration: 0.50 }}
        >
          <IconTile icon={c.icon} />
        </motion.div>

        {/* Title underline scaleX origin-right */}
        <motion.div
          initial={{ scaleX: 0 }}
          whileInView={{ scaleX: 1 }}
          transition={{ duration: 0.70, delay: 0.55 + cd, ease: [0.16, 1, 0.3, 1] }}
          style={{ originX: 1 }}
          className="h-[2px] bg-{accent}"
        />

        {/* Body bullets per-bullet stagger */}
        <ul>
          {c.bullets.map((b, bi) => (
            <motion.li
              key={bi}
              initial={{ opacity: 0, x: -8 }}
              whileInView={{ opacity: 1, x: 0 }}
              transition={{ duration: 0.50, delay: 0.65 + cd + bi * 0.07, ease: [0.16, 1, 0.3, 1] }}
            >
              <span aria-hidden>◆</span> {b}
            </motion.li>
          ))}
        </ul>
      </Card>
    </StaggerItem>
  );
})}

// Stat counts on cards
<StatCounter target={c.value} delay={0.20 + i * 0.06} />

06Springs — exactly 2 configs

Scarcity is doctrine: springs are reserved for element-pop + layoutId-shared-element-move only. DON'T bring springs to entry animations, hover states, or section reveals. Use ENTER_EASE.

6.1 · Icon tile pop-in (moderate bounce)

  initial={{ scale: 0.5, opacity: 0 }}
  whileInView={{ scale: 1, opacity: 1 }}
  transition={{ type: "spring", stiffness: 260, damping: 18, delay: 0.30 + cd }}
>
  <IconTile icon={icon} />
</motion.div>

// Effective duration ~0.5s. Moderate bounce — feels alive, not springy.

// TrustTabs active border ring sliding to clicked tab

  layoutId="activeTab"
  className="absolute inset-0 ring-2 ring-{accent} rounded"
  transition={{ type: "spring", stiffness: 380, damping: 32 }}
/>

// Snappier than 260/18. No overshoot. Controlled feel.
