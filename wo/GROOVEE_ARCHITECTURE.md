### Internal-Linking Silo (how the authority is built)
Hubs → spokes: Services hub → the 5 services · Systems hub → the 12 systems · Project-Types hub → the 6 types · Service-Areas hub → 7 county hubs → attested town pages · Resources hub → articles → glossary terms. ### Build Gates (the architecture names its own verifiers — doctrine §19)
The build that executes this architecture must pass, mechanically:
- **Anti-doorway:** pairwise similarity **<40%** across all location pages (token-shingle overlap, word n-gram Jaccard n≈5, on RENDERED MAIN-CONTENT text only — nav/footer/shared CTA/schema excluded before comparison) + delete-the-city-name **≥4 real local signals** per location page (for expansion-register pages these are coverage signals — real drive-time, county, real geography — never invented work). Gate lists **DERIVED from site config**, never hardcoded.
- **Reachability:** every sitemap route ≤2 hops from home (BFS the nav — Built ≠ Reachable).
- **Sitemap count floor:** **134 routes** (per Total Scope, adjusted 1:1 with attestation cuts) — a silent drop fails the build.
- **Expansion-register honesty gate (this architecture's load-bearing gate):** zero completed-work language, zero job counts, zero neighborhoods arrays, zero "projects in {town}" modules, zero work-claiming alt text on ANY location page — automated regex/component audit + manual review, audited against the (currently empty) job book. When real jobs exist, every future work-claim gets a scrub-table disposition (KEEP-supported / CONVERT / DELETE) with a NAMED auditor (the §18 judge, else the operator).
- **Verify-or-cut (doctrine §18):** every new factual specific (geography, HOA, landmark, licensing claim) carries a verified primary source or is generalized/cut — an independent web-verifying judge is part of the pipeline, not polish.
- **Distinctness:** no clause of 8+ words repeated across pages in main-content prose; FAQ questions AND answers each on their own construction; stylometric tells (em-dash density, hedge-word distribution, repeated closers) merge-blocking.
- **Trademark gate (trade-specific):** automated crawl asserts no brand token (Govee, Trimlight, Jellyfish, Gemstone — case-insensitive) appears in any slug, title, H1, or schema `brand` field; nominative body-copy mentions only.
- **Schema gate:** zero self-serving `aggregateRating` anywhere (doctrine §10 lock); LocalBusiness subtype matches the attested licensing status.
- **Cannibalization gate:** every row of the head-term mapping table resolves to exactly ONE indexable URL; a second indexable URL targeting a mapped head term fails the build.
